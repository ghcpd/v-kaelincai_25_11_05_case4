# Project_A_Flaky

This project demonstrates a flaky, race-prone grading service.

Setup:
- Run `bash setup.sh` to create venv and install dependencies.
- On Windows PowerShell, use the PowerShell instructions inside `setup.sh`.

Run tests:
- `bash run_tests.sh` or `.\run_tests.ps1` in PowerShell. Results are written to `../results/results_pre.json` and console.
